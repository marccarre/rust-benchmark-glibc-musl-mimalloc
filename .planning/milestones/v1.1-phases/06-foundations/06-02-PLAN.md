Required public API surface in `crates/alloc-bench-aggregator/src/loader.rs`:

```
pub struct SecurityMeta {
    pub env: String,
    pub score: u8,            // 0..=100, NOT range-validated at parse time

    pub captured_at: String,
}

pub fn load_security_metas(pattern: &str) -> Result<BTreeMap<String, SecurityMeta>>;
```

Behavior contract (verbatim mirror of load_cell_metas at loader.rs:79-101 with three deviations):
1. Empty pattern → return `Ok(BTreeMap::new())` immediately (no glob, no I/O).
2. Otherwise: `glob::glob(pattern)?.filter_map(|r| r.ok()).collect::<Vec<PathBuf>>()`, then `paths.sort_unstable()`.
3. For each path: `match load_one_security_meta(&path)` — Ok inserts into map keyed on `meta.env.clone()`, Err logs `eprintln!("warn: skipped security meta {}: {}", path.display(), e)` (note: distinct grep token "security meta") and continues.
4. Return type is `BTreeMap<String, SecurityMeta>` (env-keyed) — NOT `HashMap`, NOT a `(String, String)` tuple key.
5. Imports added to loader.rs: `use std::collections::BTreeMap;` (existing file uses only `HashMap` — must add this import). DO NOT remove `use std::collections::HashMap;` — `load_cell_metas` still uses it.
