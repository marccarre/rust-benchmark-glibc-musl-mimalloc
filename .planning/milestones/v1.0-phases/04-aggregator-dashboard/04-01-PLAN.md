## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → aggregator | Untrusted JSON input from `results/*.json` parses through serde-derived structs. Forward-compat (unknown additive fields) per D-06; major schema mismatches rejected. CDN compromise becomes a hard browser fail (refuses to execute) instead of a silent supply-chain attack. The aggregator itself never fetches the CDN. |
| aggregator → filesystem (write side) | Aggregator writes `report/index.html` and `report/REPORT.md` into a user-specified directory. `std::fs::create_dir_all` may create parent paths; we accept this (the user passed `--output`). No symlink-following risk because we control the only writes. |
| browser → file:// (report viewer) | The dashboard runs in a `file://` URL — same-origin policy treats every other `file://` as cross-origin. The page reads only inlined JSON (no fetch calls); the only network activity is the Plotly CDN load (mitigated above). No user-supplied input crosses into the dashboard at runtime. |
