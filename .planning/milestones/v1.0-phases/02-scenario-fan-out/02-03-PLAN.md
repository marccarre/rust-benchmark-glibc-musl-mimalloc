<objective>
Wire all 10 scenarios (1 from Phase 1 + 6 from Plan 01 + 3 from Plan 02) into a single `run-all` command that executes them sequentially with light default configs (per-scenario warmup=1s + duration=5s) and aggregates per-scenario `Run` records into one combined results.json. Add the DCE verification recipe + script that proves `__rust_alloc` call sites survive `--release --emit=llvm-ir` (Phase-2 ROADMAP success criterion 4). Add an end-to-end integration test that asserts run-all produces 10 records, isolates failures via `panic::catch_unwind` (CONTEXT.md decision), and validates the combined JSON shape.

Purpose: This is the final plan that proves all 10 scenarios cohere on the same harness contract — a smoke that fails here means a scenario added in Plan 01 or Plan 02 has a regression. The DCE recipe is the documented Phase-2 ROADMAP gate against compiler-driven elision. The run-all registry uses dynamic dispatch (Box<dyn Scenario>) per RESEARCH.md §Run-all recommendation, so adding a v2 scenario only touches the registry function.

- `Run` extended with `Option<String>` `status` and `error` fields (additive only — `ScenarioInfo.unit` was added in Plan 01)

3. Implement `run_all`:
   ```rust
   pub fn run_all(output: Option<&str>, seed: u64) -> anyhow::Result<()> {
       use std::time::Duration;
       let cfg = alloc_bench_core::HarnessConfig {
           warmup: Duration::from_secs(1),
           measure: Duration::from_secs(5),
           seed,
       };
       let mut runs: Vec<alloc_bench_core::output::Run> = Vec::new();

       for (name, unit, builder) in default_scenarios(seed) {
           // Per CONTEXT.md decision: continue on per-scenario failure.
           // Wrap each builder + run() in catch_unwind so panics become
           // records, not aborts.
           let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
               let mut scenario = builder()?;
               let outcome = alloc_bench_core::run(&mut *scenario, &cfg, crate::allocator::stats)?;
               let scenario_name = scenario.name().to_string();
               let scenario_config = scenario.config_json();
               assemble_run(&scenario_name, scenario_config, unit.clone(), outcome,
                            Some("success".to_string()), None)
           }));
           match result {
               Ok(Ok(run)) => runs.push(run),
               Ok(Err(e)) => runs.push(degenerate_failure_run(name, e.to_string())?),
               Err(panic) => runs.push(degenerate_failure_run(name, panic_message(&panic))?),
           }
       }

       let json = serde_json::to_string_pretty(&runs)?;
       match output {
           Some(path) => std::fs::write(path, &json)
               .with_context(|| format!("writing run-all results to {path}"))?,
           None => println!("{json}"),
       }
       Ok(())
   }
   ```

Uses `alloc_bench_core::metrics::env::read_env()?` and the same Build construction as `assemble_run`. The "harness" + "metrics" sub-records have zero values (warmup_duration_s=0.0, ticks_per_s=0.0, etc.) — the `error` field is the source of truth for failure cases.

Per RESEARCH.md §A8: `AssertUnwindSafe` is required because the closure captures mutable scenario state (the boxed scenario itself).
