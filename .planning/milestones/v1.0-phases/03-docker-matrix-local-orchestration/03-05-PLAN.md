## 11. Justfile cross-product matrix

The repository ships a `justfile` with the following Phase-3 recipes (see `just --list`):

| Recipe | Purpose |
|--------|---------|
| `build {env} {alloc}` | Build one cell `alloc-bench:{alloc}-{env}` via `docker buildx build --platform linux/amd64 -f docker/{env}.Dockerfile`. Validates cross-libc combos. |
| `run {env} {alloc}` | Run one cell with default cgroup flags (`--cpus=4 --memory=4g --cpuset-cpus=0-3`); writes `results/{alloc}-{env}.json`. Override via `BENCH_CPUS`, `BENCH_MEMORY`, `BENCH_CPUSET`. |
| `bench-cell {env} {alloc}` | `build` + `run` chained. |
| `bench-all` | Sequentially runs the full 18-cell matrix (`{ptmalloc,jemalloc,mimalloc} × {debian-slim,distroless-cc,wolfi}` + `{mallocng,jemalloc,mimalloc} × {alpine,distroless-static,scratch}`); per-cell error capture; ends with stdout summary table. |
| `bench-all-smoke` | Same loop with smoke-defaults (currently aliased to `bench-all` since run-all already uses warmup=1s + duration=5s per scenario). |
| `bench-host` | Build + run natively on the host (no Docker); writes `results/host-system.json` (macOS libmalloc baseline). |
| `dive-check {env} {alloc}` | `dive --ci` against one image using `.dive-ci` thresholds. Falls back to dockerized wagoodman/dive:latest if host dive isn't installed. |
| `dive-check-all` | `dive-check` for every cell in the matrix. |
| `clean-images` | Remove all `alloc-bench:*` Docker tags. |

Cross-libc combos (mallocng on glibc, ptmalloc on musl) are **structurally** absent from `_matrix_cells` AND hard-rejected with a `[ERR]` message in the `build` recipe.

`docker run` and `docker buildx build` invocations always pass `--platform linux/amd64` (Apple Silicon dev box would otherwise default to arm64). The `run` recipe pre-creates `./results` with `chmod 0777` for distroless nonroot UID 65532 write access.

For full Phase-3 evidence (per-cell sizes, dive scores, OCI labels, escape-hatch drops), see `.planning/phases/03-docker-matrix-local-orchestration/03-04-SMOKE-RESULTS.md`.
