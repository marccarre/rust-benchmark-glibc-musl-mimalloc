All template surfaces invoke the two .tmpl files Plan 01 already authored.

Purpose: Phase 8's user-visible deliverables — a navigable top-10 view in REPORT.md and the dashboard, plus 10 standalone fragments per format for future drilldown linking. Honors the Q1 lock (insert AFTER `emit_recommendations`; do NOT reorder existing sections), Q5 lock (compute in main.rs, thread as new param — option B), Q3 lock (leading `| Rank | Cell | Score |` summary table is in-scope, emitted before the cards), and the visible/collapsed split rule (top-5 above the fold + 5 inside `<details>` per CELL-04 / Cowan's 4±1).
Output: One modified `main.rs` (orchestration), one modified `markdown.rs` (`emit_top_n_cells` + leading summary table + per-cell .md writes), one modified `html.rs` (`HtmlContext` extension + register-templates + per-cell .html writes), one modified `index.html.tmpl` (new `<section>` block gated by `{{if has_top_n}}`).
