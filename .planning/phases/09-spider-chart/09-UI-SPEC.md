# Phase 9 — UI Design Contract

> Visual and interaction contract for the top-3 spider-chart small-multiples grid (`<div id="chart-spider">` in `report/index.html`), the matrix-mean reference polygon overlay, the heuristic-axis distinction (`(heuristic)` suffix + muted `#666` tickfont), and the Pareto-front overlay column (`★` glyph) on the existing Recommendations table. Generated by gsd-ui-researcher; verified by gsd-ui-checker.

This phase ships **server-side scatterpolar trace JSON builders** rendered by the Plotly v2.35.3 CDN bundle already pinned in `index.html.tmpl` line 18 (with SRI integrity). The visual surface inherits from the v1.0 design system declared in `crates/alloc-bench-aggregator/templates/index.html.tmpl` lines 22-58 — no new CSS variables, no new typography tokens, no new color tokens beyond the two greyscale rgba shades reserved for the reference polygon.

**Per-cell trace color:** Plotly default `colorway` cycles automatically per top-3 cell (no manual color assignment per allocator inside the spider chart). Reason: avoids hand-picking per-allocator colors which would diverge from per-scenario charts that already use the Viridis-derived `ALLOC_COLORS` map (lines 361-366) for the bar/line surfaces. Reference polygon's grey tone visually distinguishes from any per-cell color.

**Pareto-front `★` glyph color:** inherits from `--color-text` `#1F2328` (cell text default) — NOT accent, NOT semantic. The glyph's distinctive shape carries the signal; color stays neutral. Markdown surface emits `★` plain (GFM applies inherited text color).

**Heuristic-axis distinction (POLAR-03):**

- **Primary signal:** `(heuristic)` suffix in the angular tick label (11-byte literal ` (heuristic)` with leading space) — present on both heuristic axes (`image_size_efficiency` and `security_posture`).
- **Secondary signal:** muted `#666` color on the heuristic angular tick text (vs `#222` for real-measurement axes).
- **Why both signals:** Plotly v2.35.3 `polar.angularaxis` does not support per-tick `gridcolor` overrides — the `(heuristic)` suffix is the textual cue, the muted color is the visual cue. CONTEXT.md decision row explicitly locks both.

**WCAG color-contrast verification:**

- Section heading `#1F2328` on white → 14.4:1 (AAA Normal + AAA Large)
- Chart per-cell title `#1F2328` on white → 14.4:1 (AAA)
- Real-measurement angular ticks `#222` on white → 16.0:1 (AAA)
- Heuristic angular ticks `#666` on white → 5.7:1 (AA Normal at 11px, AAA Large) — meets WCAG AA SC 1.4.3 floor for normal text
- Reference polygon fill `rgba(128,128,128,0.25)` over white → ≥ 1.7:1 effective; this is decorative chart fill (NOT text, NOT functional UI), exempt from WCAG contrast requirements per SC 1.4.11 graphical-objects exception (the polygon is purely contextual reference, not the primary information carrier)
- Pareto `★` glyph `#1F2328` on white → 14.4:1 (AAA); shape redundancy (text glyph) ensures meaning is not color-dependent

## Accessibility

**Semantic HTML:**

- `<section class="spider-chart">` — landmark for the spider visual region; sits at the same hierarchy level as the existing `<section class="report-mirror">` and `<section class="top-n-recommendations">` (h2-rooted sections).
- `<h2>Top-3 Above the Fold</h2>` — section heading nested under the page `<h1>alloc-bench report</h1>` (line 220 of index.html.tmpl).
- `<p>` for caption — semantic paragraph, screen-reader-announced as block.
- `<div id="chart-spider" class="spider-grid">` — Plotly target container; Plotly v2.35.3 injects its own SVG with internal ARIA attributes.

**Headings hierarchy:** h1 (`alloc-bench report`) > h2 (`Top-3 Above the Fold`) > [no h3 in this section — chart per-cell titles are Plotly-rendered into the SVG, not HTML headings]. No skipped levels.

**ARIA:**

- Plotly v2.35.3 emits `<svg role="img" aria-label="...">` automatically for scatterpolar charts (Plotly accessibility default). The `aria-label` defaults to the chart title (`{alloc}/{env}`).
- NO custom `aria-*` attributes added in Phase 9 beyond Plotly's injection.
- Direction-marker `aria-label` wrappers (`<span aria-label="higher is better">↑</span>`) arrive in Phase 10 (DIR-04), NOT in this phase.

**Color contrast:** see **Color** section above. All foreground text (real-measurement ticks `#222`, heuristic ticks `#666`, section heading + caption `#1F2328`) passes WCAG AA on white. Reference polygon fill at 25% alpha is decorative chart geometry (SC 1.4.11 graphical-objects exception applies — polygon is contextual reference, not the primary information carrier; cell polygon's solid fill carries the per-cell signal).

**Color-blind safety:**

- Heuristic distinction does NOT rely on color alone — the `(heuristic)` suffix in the angular tick label is the primary cue (textual, color-blind-safe). Muted color is secondary.
- Per-cell polygon colors come from Plotly's default colorway which is colorblind-aware for ≤3 series; with only 3 cells in the small-multiples grid, color collisions are not a concern.
- Reference polygon's grey is achromatic (no hue) — distinguishable from any allocator color regardless of color-vision deficiency.
- Pareto `★` glyph signal is shape-based, NOT color-based — color-blind users see the star unambiguously.

**Focus management:**

- Plotly chart containers receive focus when tabbed to; arrow-key navigation moves focus across data points (Plotly v2.35.3 default).
- Section heading is reachable in Tab order through standard heading-flow semantics (when a screen reader's heading-jump hotkey is used).
