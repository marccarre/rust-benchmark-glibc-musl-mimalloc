The `bench-all` recipe (justfile lines 189-229) is the structural template for `build-all`:

```just
bench-all:
    #!/usr/bin/env bash
    set -uo pipefail   # NOT -e — we want to continue past per-cell failures.
    declare -a results=()
    while IFS= read -r line; do
        [[ -z "$line" ]] && continue
        env="${line%% *}"
        alloc="${line##* }"
        echo
        echo "════════════════════════════════════════════════════════"
        echo "[${alloc}-${env}] starting"
        echo "════════════════════════════════════════════════════════"
        if just bench-cell "$env" "$alloc" 2>&1 | sed "s/^/[${alloc}-${env}] /"; then
            results+=("OK   ${alloc}-${env}")
        else
            results+=("FAIL ${alloc}-${env}")
        fi
    done <<< '{{_matrix_cells}}'
    echo
    echo "════════════════════════════════════════════════════════"
    echo "Matrix summary"
    echo "════════════════════════════════════════════════════════"
    printf '%s\n' "${results[@]}"
```

The `clean-images` recipe (justfile lines 146-150) — `clean-all` MUST replicate (not call) its body:

```just
clean-images:
    #!/usr/bin/env bash
    set -uo pipefail
    docker images --filter "reference=alloc-bench:*" --format '{{ "{{" }}.Repository{{ "}}" }}:{{ "{{" }}.Tag{{ "}}" }}' \
        | xargs -r docker rmi -f
```

Why replicate, not call: `clean-all` invoking `just clean-images` would interleave `set -e` semantics (clean-images uses `set -uo`, but invoking via `just` re-enters with the recipe's own pipeline; safer + more transparent to inline). Per locked decision 5, ordering is docker-first, fs-second, cargo-last with per-step `|| true`.

The `_matrix_cells` variable (lines 159-178) is referenced in `bench-all` via `<<< '{{_matrix_cells}}'`. Use the same interpolation form in `build-all` — no need to redefine or re-parse.

The `build` recipe (lines 43-112) takes `env alloc` positional args and produces `alloc-bench:{alloc}-{env}` images. `build-all` invokes it via `just build "$env" "$alloc"` per row.

The `bench-host` recipe (lines 257-265) shows the canonical host-build invocation:

```just
bench-host:
    #!/usr/bin/env bash
    set -euo pipefail
    mkdir -p results
    cargo build --release -p alloc-bench-cli
    target/release/alloc-bench-cli run-all --output results/host-system.json --seed 7
```

`build-all` reuses ONLY the `cargo build --release -p alloc-bench-cli` line — no `mkdir results`, no `run-all` invocation. (build-all is build-only by definition.)
