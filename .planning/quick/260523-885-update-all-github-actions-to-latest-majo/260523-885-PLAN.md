# Quick Task 260523-885: Update all GitHub Actions to latest major versions

## Context

`.github/workflows/bench.yml` pins every third-party action to a stable major. Several majors are 1–4 versions behind upstream (Node 20 → Node 24 runtime migration; ESM upgrades on `docker/*` and `actions/*`). The CLAUDE.md "GHA action pinning" convention mandates major-version pins, so the goal is to bump each to its current latest major while preserving the convention. The `ubuntu-24.04` runners ship Actions Runner ≥ v2.327.1, so the Node 24 requirement of every new major is satisfied with no infra change. See approved upstream plan: `/Users/marc.carre/.claude/plans/update-all-github-actions-concurrent-donut.md`.
